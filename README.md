# Skypro Shop — Интернет-магазин на Django

## Описание проекта
Данный проект представляет собой полноценное веб-приложение для интернет-магазина, разрабатываемое в рамках курса Skypro. Проект строится на базе современного веб-фреймворка Django с использованием архитектурного паттерна MVT (Model-View-Template).

## Технологический стек
- **Язык программирования:** Python 3
- **Веб-фреймворк:** Django
- **Управление зависимостями:** Poetry
- **Верстка и стилизация:** Bootstrap 5
- **Линтеры и форматтеры:** Flake8, Black, Isort

## Как запустить проект локально

1. Убедитесь, что у вас установлен Poetry.
2. Установите зависимости проекта:
   ```bash
   poetry install
   ```
3. Запустите сервер разработки Django:
   ```bash
   poetry run python manage.py runserver
   ```
4. Откройте в браузере адрес: http://127.0.0.1:8000/
