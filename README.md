# Skypro Shop

Современное веб-приложение для электронной коммерции, разработанное на стеке Python и Django с использованием архитектурного паттерна MVT (Model-View-Template). Проект спроектирован с упором на модульность, чистоту кодовой базы и изоляцию компонентов.

## Функционал и особенности архитектуры

- **Модульная структура приложений**: Логика каталога изолирована в рамках независимого приложения `catalog`, что позволяет легко масштабировать проект в будущем.
- **Безопасная маршрутизация**: Использование пространств имен (`namespace`) для полной изоляции URL-схем и динамической генерации путей.
- **Управление статическими ресурсами**: Независимая локальная сборка статических файлов (CSS/JS) на базе инструментов Django Static без привязки к внешним CDN-сетям.
- **Интерактивные формы обратной связи**: Реализована безопасная обработка POST-запросов (с защитой от CSRF-атак) для взаимодействия с пользователями, логированием входящих данных на сервере и мгновенными уведомлениями на клиенте.

## Технологический стек

- **Backend:** Python 3, Django 6
- **Frontend:** HTML5, Bootstrap 5
- **Пакетный менеджер:** Poetry
- **Качество кода (QA):** Black, Isort, Flake8 (PEP 8)

## Быстрый старт (Локальный запуск)

1. Убедитесь, что в системе установлен менеджер зависимостей **Poetry**.
2. Клонируйте репозиторий и установите все необходимые зависимости проекта:
   ```bash
   poetry install
   ```
3. Выполните миграции для подготовки локальной базы данных:
   ```bash
   poetry run python manage.py migrate
   ```
4. Запустите локальный веб-сервер разработки:
   ```bash
   poetry run python manage.py runserver
   ```
5. Откройте проект в браузере по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Контроль качества кода

Проект поддерживает строгие стандарты оформления кода PEP 8. Перед фиксацией изменений рекомендуется запускать комплексную проверку кодовой базы:

```bash
poetry run isort catalog/
poetry run black catalog/
poetry run flake8 catalog/
```
